# Retail Sales ETL Project

## About Project
This project performs ETL (Extract, Transform, Load) on retail sales data using Python and PostgreSQL.

## Technologies Used
- Python
- Pandas
- PostgreSQL
- SQL
- Git & GitHub

## Project Workflow
1. Extract data from CSV file.
2. Clean and transform data using Python.
3. Load cleaned data into PostgreSQL.
4. Perform SQL analysis.

## Analysis
- Total Revenue
- Product-wise Revenue
- Monthly Revenue
- Customer-wise Revenue
- Product-wise Quantity

## Project Status
ETL Pipeline and SQL Analysis completed.
